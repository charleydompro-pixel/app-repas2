# Prototype Repas

Prototype React/Vite créé à partir de `app-repas-v3.jsx`.

## Lancer l'application

1. Installer Node.js (version 18 ou plus récente recommandée).
2. Ouvrir un terminal dans ce dossier.
3. Exécuter :

```bash
npm install
npm run dev
```

4. Ouvrir l'adresse affichée par Vite (généralement http://localhost:5173).

## Créer une version de production

```bash
npm run build
npm run preview
```

Le dossier `dist/` contient alors la version construite.
